## 6. Experiment with Frame Sampling

Next, we explored a more efficient way to examine the longer video.

Instead of processing every frame, we used Ultralytics streaming inference with:

`stream=True`

and

`vid_stride=25`

The frame stride instructed the model to process approximately every 25th frame.

We also used:

- Confidence threshold: 0.25.
- Inference device: CPU.
- Model: YOLO11n.
- Input: `data/raw/youtube_test.mp4`.

### Why use frame sampling?

A video containing tens of thousands of frames can take considerable time to process on a CPU.

Sampling allows us to inspect a large video using fewer inference operations. It is useful for preliminary analysis, although objects can be missed between sampled frames.

## 7. Understand Detection Confidence

During the visual inspection, we observed confidence labels such as:

- Car: 0.84
- Car: 0.76
- Truck: 0.67
- Car: 0.65

A confidence score represents the model's confidence in an individual prediction.

For example, a score of 0.84 means the model assigned that prediction a confidence score of 0.84.

It does not mean the model has an overall accuracy of 84%.

The confidence threshold of 0.25 determines which predictions are retained by our inference configuration. It is a setting we can evaluate later rather than a value that is automatically optimal for every traffic scene.

## 8. Detection Is Not the Same as Tracking

One of the most important lessons from Day 5 was understanding why accumulated detections cannot be treated as unique-vehicle counts.

Imagine one car appears in 100 consecutive frames.

If the model detects that car in each frame, it may contribute approximately 100 detections to our accumulated count.

It is still only one physical car.

To count individual vehicles reliably, RoadFlow AI will need an object-tracking approach that associates detections across frames and maintains persistent track IDs.

Our future system will need to distinguish between:

1. Object detection: identifying objects in individual frames.
2. Object tracking: associating the same object across multiple frames.
3. Vehicle counting: determining when a tracked vehicle crosses a defined counting boundary or satisfies another counting rule.
4. Traffic forecasting: using suitable traffic measurements and historical data to estimate future traffic conditions.

We have not yet implemented persistent object tracking, unique-vehicle counting, or traffic forecasting.
