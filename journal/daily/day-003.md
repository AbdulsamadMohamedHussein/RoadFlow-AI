# Day 3 — Python Environment and First AI Inference

**Date:** October 18, 2026

## Objectives

- Establish an isolated Python environment for RoadFlow AI.
- Install and verify the initial AI and computer-vision libraries.
- Create the first source-code file in the new repository.
- Run and visually verify a pretrained YOLO model.
- Record progress and prepare the next development milestone.

## Work completed

- Created the `.venv` virtual environment inside RoadFlow-AI.
- Activated the virtual environment and verified Python 3.14.7.
- Checked `.gitignore` to confirm virtual-environment files are excluded from Git.
- Installed Ultralytics, OpenCV, and PyTorch.
- Verified successful imports and recorded the installed library versions.
- Confirmed PyTorch is using a CPU-only build; CUDA is unavailable in this environment.
- Created `src/roadflow/detect_image.py`.
- Loaded the pretrained YOLO11n model.
- Ran inference on a sample bus image.
- Verified the annotated image visually.

## Technical results

- Ultralytics: 8.4.182
- OpenCV: 5.0.0
- PyTorch: 2.14.1+cpu
- Python: 3.14.7
- Device used: CPU
- Sample image dimensions: 640 x 480
- Inference output: 5 detected objects
- Detected classes: 1 bus and 4 people
- Bus confidence: 0.94
- Person confidence scores: 0.89, 0.88, 0.86, and 0.62

These confidence scores describe individual detections, not overall model accuracy.

## Files and artifacts

- `src/roadflow/detect_image.py` — initial image-detection program.
- `yolo11n.pt` — downloaded pretrained model weights in the local project root.
- `bus.jpg` — downloaded sample input image in the local project root.
- `runs/detect/runs/roadflow/first_detection/bus.jpg` — saved annotated detection output.

The model weights and generated outputs are local artifacts and should not be committed to Git by default.

## What I learned

- A Python virtual environment isolates project dependencies.
- YOLO performs inference using a pretrained neural network.
- OpenCV provides computer-vision and image/video-processing tools.
- Detection confidence is not the same as model accuracy.
- A successful terminal run should be followed by visual verification.
- CPU inference is possible without an NVIDIA GPU, although performance may be limited.

## Problems and observations

- The first run downloaded the pretrained model weights and sample image.
- Ultralytics displayed a settings-schema update warning; inference still completed successfully.
- The annotated output was saved in a nested directory because of the configured output path.
- The initial detection image contained overlapping bounding boxes that may require further evaluation.
- No traffic-video processing has been implemented or verified yet.

## Evidence

- Terminal output confirming successful library imports.
- Terminal output confirming five detections.
- Annotated sample image opened and visually inspected.
- Local output file located under the generated runs directory.

## Decisions made

- RoadFlow AI is being developed as a fresh, independent repository.
- The implementation will be developed and tested inside RoadFlow-AI.
- The initial pipeline will use pretrained weights before considering model training.
- CPU inference will be used initially.
- Large model files, virtual environments, raw datasets, and generated outputs should remain outside Git unless there is a justified reason to version them.
- Features will be documented as completed only after verification.
