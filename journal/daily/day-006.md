# Day 6 — Evaluating Vehicle Detection Confidence Thresholds

**Date:** October 21, 2026

## Objectives

- Understand how YOLO confidence thresholds affect vehicle detection.
- Compare three thresholds using the same sampled video frames.
- Examine annotated images for possible missed detections and classification errors.
- Establish a measured baseline before improving the main RoadFlow AI pipeline.

## Work Completed

- Confirmed that the local Git repository was synchronized with origin/main.
- Confirmed that journal/daily/day-005.md exists.
- Reviewed src/roadflow/detect_video.py without modifying the main detector.
- Loaded the existing pretrained YOLO11n model.
- Used data/raw/youtube_test.mp4 as an experimental video input.
- Read the first 250 frames and sampled every fifth frame, producing 50 frames for evaluation.
- Ran inference on the same sampled frames using confidence thresholds of 0.25, 0.50, and 0.75.
- Counted detections by predicted class.
- Generated three annotated images from the same selected frame for visual comparison.

## Experimental Setup

- Model: YOLO11n pretrained weights (yolo11n.pt)
- Input video: data/raw/youtube_test.mp4
- Inference device: CPU
- Video resolution: 640 x 360
- Video frame rate: 25 FPS
- Frames read for sampling: up to the first 250 frames
- Sample interval: every fifth frame
- Sampled frames: 50
- Confidence thresholds: 0.25, 0.50, and 0.75

The experiment was conducted without changing the main video-detection program.

|---|---:|---:|---:|
| Car | 414 | 279 | 74 |
| Truck | 67 | 26 | 2 |
| Bus | 20 | 11 | 6 |
| Total | 501 | 316 | 82 |

These values represent detections across sampled frames. They do not represent unique vehicles, and they are not measurements of model accuracy.

## Visual Comparison

Three annotated images were generated from the same selected frame, at frame index 75.

- Threshold 0.25: 12 detections.
- Threshold 0.50: 6 detections.
- Threshold 0.75: 0 detections.

The comparison showed that increasing the confidence threshold removed many predictions. At 0.75, no detections passed the threshold in the selected frame, although vehicles remained visibly present.

The lower-threshold image showed several vehicle detections, overlapping boxes, and a possible truck-versus-bus classification issue that requires further inspection.

## Technical Interpretation

A confidence threshold determines which predictions are retained.

A lower threshold retains more predictions, including potentially incorrect ones. A higher threshold rejects more low-confidence predictions, but can also remove valid detections.

The results demonstrate that the number of retained predictions decreases as the threshold increases.

However, detection counts alone cannot establish which threshold performs best. Reliable precision and recall measurements require manually verified ground-truth labels.

The possible classification error and overlapping boxes observed in the images are qualitative observations, not yet verified error rates.

## What I Learned

- Confidence is not the same as accuracy.
- A detection count is not a unique-vehicle count.
- Raising a threshold can reduce detections without necessarily improving real-world performance.
- Visual inspection helps identify possible failure cases but does not replace quantitative evaluation.
- A controlled comparison requires using the same frames and model settings apart from the variable being tested.

## Limitations

- No ground-truth annotations were available.
- Precision, recall, and classification accuracy were not calculated.
- The 50 sampled frames do not represent the entire video.
- Potential classification errors and overlapping boxes have not been systematically measured.
- CPU inference was used; no GPU performance comparison was conducted.

Day 6 established an initial experimental baseline for confidence-threshold evaluation in RoadFlow AI.

The experiment showed that changing the confidence threshold substantially affects the number of retained vehicle detections. Visual inspection also identified possible missed vehicles, overlapping boxes, and a potential vehicle-classification issue.

The next step is to evaluate detection quality against verified labels rather than relying on detection counts alone.
