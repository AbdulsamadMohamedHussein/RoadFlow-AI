# RoadFlow AI 🚦

**Building an AI-powered traffic intelligence platform through a 700-day engineering journey.**

## Project Overview

RoadFlow AI is a computer vision project exploring vehicle detection, vehicle tracking, and traffic analytics for smart-city applications.

The project builds on previous YOLO-based traffic-detection work and will evolve through reproducible experiments, model evaluation, software engineering, and deployment.

## Main Goals

- Develop and evaluate vehicle-detection models.
- Explore tracking vehicles across video frames.
- Extract useful traffic statistics.
- Build a documented backend API and dashboard as the project develops.
- Measure model performance and document limitations.
- Maintain a transparent record of the engineering journey.

## Technology Stack

- Python
- YOLO and OpenCV
- NumPy and pandas
- FastAPI
- Git and GitHub
- pytest

Technologies and features will be added as they are implemented and tested.
